# OSD32MP1-BRK Device Tree
This repository contains the device tree sources for OSD32MP1-BRK

## Requirements

| Package | Version |
| ------- | ------- |
| OpenSTLinux Developer Package | 6.6-yocto-scarthgap |
| U-Boot version | u-boot-stm32mp_2023.10 |
| TF-A version | tf-a-stm32mp_2.10 |
| Kernel version | linux-stm32mp_6.6 |
| OPTEE version  | optee-os-stm32mp_4.0.0 |

Developer Package: https://wiki.st.com/stm32mpu/wiki/STM32MPU_Developer_Package 
How to cross compile: https://wiki.st.com/stm32mpu/wiki/How_to_compile_the_device_tree_with_the_Developer_Package
